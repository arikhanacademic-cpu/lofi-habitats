# Animal recordings

Put MP3 files here named after each animal's id. The site plays the first few seconds of a recording whenever that animal "calls", and falls back to a synthesised sound if the file is missing.

Good free sources: [xeno-canto](https://xeno-canto.org/) (birds and some other animals), the [Macaulay Library](https://www.macaulaylibrary.org/) and [Freesound](https://freesound.org/). Check each recording's licence. Many are CC BY-NC or CC BY-NC-SA, which is fine for a personal, non-commercial site as long as you credit them, but "ND" licences don't allow trimming. List your credits below.

Animal ids:

savannah: lion, elephant, giraffe, zebra, wildebeest, cheetah, hyena, aardvark, vulture
rainforest: jaguar, sloth, macaw, toucan, howler, dartfrog, milkfrog, nightmonkey, morpho
reef: clownfish, parrotfish, turtle, manta, whitetip, moray, polyps, crayfish
deep: lanternfish, humboldt, krill, angler, barreleye, vampsquid, larvacean
arctic: polarbear, arcticfox, walrus, reindeer, ptarmigan, ringedseal, tern, littleauk
antarctica: emperor, emperorchick, chinstrap, weddell, leopardseal, snowpetrel, orca
desert: fennec, camel, viper, silverant, jerboa, scorpion, eagleowl
london: redfox, hedgehog, pipistrelle, pigeon, robin, tawnyowl, squirrel, parakeet
